# Security policy

## Supported versions

Security fixes are provided for the latest fastText Modern release.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting for this repository so the maintainer can
investigate before details are disclosed. Include affected versions, a minimal
reproduction, the expected impact, and any suggested mitigation.

For vulnerabilities inherited from upstream fastText, reporters may also wish
to notify the [upstream project](https://github.com/facebookresearch/fastText)
according to its current security policy.
